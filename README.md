# The_Movie_Watchlist_Project
First React Project
🎬 Movie Watchlist Project

A simple movie search and watchlist app built using public APIs. Users can search for movies and save their favorites to watch later.

🚀 Features
🔍 Live Search
Search for movies using the OMDb API (on typing or button click)
⭐ Watchlist Toggle
Add or remove movies from your personal watchlist
📭 Empty States
Friendly UI when no results are found or watchlist is empty
🎨 Modern UI
Dark theme inspired by Disney+ / HBO Max with a sticky sidebar
🎲 Optional Feature
"Random Movie Night" button to pick a movie from your watchlist
🛠️ APIs Used
OMDb API
 – Movie search data
TMDB API
 – Additional movie details
Watchmode API
 – Streaming availability
