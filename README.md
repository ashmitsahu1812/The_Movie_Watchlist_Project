#  Movie Watchlist Project

A simple movie search and watchlist web app where users can search for movies and save them to watch later.

---

##  Features

-  **Live Search**  
  Search for movies using the OMDb API (on typing or button click)

-  **Watchlist Toggle**  
  Add or remove movies from your personal watchlist

-  **Empty States**  
  Displays helpful messages when no movies are found or watchlist is empty

-  **Modern UI**  
  Dark theme inspired by platforms like Disney+ and HBO Max with a sticky sidebar

-  **Optional Feature**  
  "Random Movie Night" button to pick a movie from your watchlist

---

##  APIs Used

- OMDb API – https://www.omdbapi.com/  
- TMDB API – https://developer.themoviedb.org/docs/getting-started  
- Watchmode API – https://api.watchmode.com/
